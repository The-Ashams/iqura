# Décisions de langue — niveau Débutant 1 (leçons 0 à 4)

Décisions de l'agent `conseiller-arabe` (23/10/2026), sur les doutes des relectures. Ni validation humaine ni validation religieuse.

| # | Sujet | Décision | Confiance |
| --- | --- | --- | --- |
| 1 | Translittération dans les explications du mini-boss (leçons 1 à 4) | Gardée : elle n'apparaît qu'à la revue des erreurs, après le combat (§6.2 « visible dans les explications ») ; jamais pendant le combat. Le combat d'entraînement de la Faille, qui proposait des translittérations, est remplacé par l'Expédition | moyenne |
| 2 | ثَجَّاجًا (78:14:5), 2 ج écrits, 3 entendus (shadda) | Gardé : on compte les lettres qu'on voit ; idem وَعَدَّدَهُۥ (104:2:4). À remplacer si les tests montrent une confusion | moyenne |
| 3 | وَزَيْتُونًا (80:29:1) : ي avec sukūn | Gardé, question sur ن seulement ; ne jamais y poser de question sur ي | haute |
| 4 | Forme de pause des mots de la leçon 4 (خُبْز, بَحْر, بَدْر, دَار) | Gardée sans signe final, écran « La fin du mot » ; 2e phrase : « Dans une phrase, cette lettre porte en général une voyelle : tu l'apprendras plus tard. » | haute |
